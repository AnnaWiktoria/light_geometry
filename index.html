Drag the lamp discs, the square handles (softbox width in the top view, height in the front view) and the camera triangle. Every value stays in sync with the fields. Hover over the frame for point values. "Light" layer: warm gradient = relative illuminance, red/orange = specular reflection. "Angle" layer: green = θ within 45° ± tolerance.

Geometric model: uniform Lambertian softboxes, the object treated as a flat mirror for the reflection test, frame from a thin-lens model (W = sw·(d−f)/f). The gloss index is relative and does not predict ΔE. The angle tolerance is yours to set per your own procedure. Verify against a photo of a uniform field.
